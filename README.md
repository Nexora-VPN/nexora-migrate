# nexora-migrate

Move your users, inbounds and settings from another VPN panel into
[Nexora](https://github.com/nexora-vpn/panel). Where the old panel's link shape
allows it, your customers' subscription links keep working.

It runs on your own computer, opens a page in your browser, walks you through
five steps and then closes. Nothing is installed.

## Run

Unpack it and run `nexora-migrate` (on Windows, double-click
`nexora-migrate.exe`). Then open the link it prints.

## Supported panels

s-ui · 3x-ui · x-ui (classic and alireza0) · Marzban · PasarGuard · Hiddify ·
Marzneshin · Remnawave
